LayerProposed choice
EditorTypeScript + Vite; native browser UI, no rich-text framework
BackendOne Worker serving assets and API; D1 SQLite for documents and revisions
Document modelTitle + ordered sections: stable ID, HTML, CSS; integer revision
Agent interfacelist_documents, get_document, create_document, update_document; updates require expected revision
AccessSingle owner; revocable scoped agent token; owner browser session; no credentials in share links
PublishingOwner publishes a revision; unguessable read-only URL; revoke or republish explicitly
Hosting costTarget $0 within Cloudflare free quotas, using workers.dev; limits must be checked before deployment
AI runs through your existing Codex access. Codex itself is not guaranteed free.
  1. Create a private document in the browser or through Codex.
  2. Ask Codex to turn workspace information into HTML components.
  3. Codex reads the current revision, generates sections, and saves through MCP.
  4. Review rendered sections; edit HTML/CSS, reorder sections, and save. Refresh detects agent updates; dirty edits are preserved.
  5. Publish the reviewed revision and copy its read-only link.
  6. Continue private edits; republish when ready. Restore an earlier revision if needed.
